# 比较中日市场信号

## 目标

每轮只记录一条 A 股宽基指数与日经225之间的同步或分化现象，长期积累可被反例修正的跨市场观察。

## 单次闭环

1. 阅读 Drift Briefing 和 journal，确认当前两组数据的时间是否可比。
2. 选择一个同步上涨、同步下跌或明显分化现象，用两个独立来源查找共同宏观背景。
3. 不强行构造因果；证据不足时只记“同期现象”和待验证假设。
4. 用 `journal_append(entry_type="progress", ...)` 记录，key 用日期+中日指数组合。
5. 默认静默积累；只有出现明显、可验证的跨市场信号时才 `message_push`。
6. 调用 `finish_drift`；暂时缺数据时用 `paused + scratchpad_update`。

## 约束

- 不给出交易指令，不声称能预测下一交易日。
- 清楚标注数据延迟、时区和交易时段差异。
- `message_push` 最多一次，发送后立即收尾。
